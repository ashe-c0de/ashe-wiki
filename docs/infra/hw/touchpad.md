## 💻 Windows

### 基础点击与选择
- **单击：** 单指轻点触控板任意位置（相当于鼠标左键）。
- **双击：** 单指快速轻点两次（用于打开文件或选中文字）。
- **右击：** **双指**同时轻点触控板（相当于鼠标右键，呼出菜单）。
- **拖动：** 单指点按目标后不抬起，直接滑动手指；或轻点两下（第二下按住不放）并拖动。
- **选中文字：** 起始位置单指点按（或轻点两下，第二下按住不放），然后拖动光标至结束位置。

### 多指手势
- **📜 滚动页面：** **双指**在触控板上同时上下滑动（浏览网页/文档）。
- **🔍 缩放内容：** **双指**捏合（缩小）或张开（放大），常用于地图或照片。
- **🗂️ 任务视图：** **三指向上**轻扫，查看所有打开的窗口和虚拟桌面。
- **🖥️ 显示桌面：** **三指向下**轻扫，最小化所有窗口，快速回到桌面。
- **🔄 切换应用：** **三指向左/右**轻扫，在最近使用的两个应用之间快速切换（类似 `Alt` + `Tab`）。
- **🔎 搜索/助手：** **三指轻点**（部分设备支持），唤出搜索栏。
- **📢 通知中心：** **四指轻点**


## 🍎 macOS

### 基础点击与选择
- **主按钮（左键）：** 单指轻点。
- **辅助按钮（右键）：** **双指**轻点。
- **拖移：** 单指或双指按住并移动。
- **选中文字：** `三指拖移`： 开启“三指拖移”功能后，用三根手指在触控板上滑动，即可像使用鼠标一样流畅地框选文字。OR `按住 Shift 键`： 单击起始位置，按住 Shift 键，再单击结束位置，可快速选中大片文本。

### 多指手势
- **📜 滚动：** **双指**上下滑动（macOS 默认“自然滚动”，即手指上推，内容下移）。
- **🔍 缩放：** **双指**捏合或张开。
- **🚀 调度中心：** **三指/四指向上**轻扫，查看所有窗口和桌面空间。
- **📉 应用程序窗口：** **三指/四指向下**轻扫，显示当前应用的所有窗口。
- **🏠 切换全屏应用：** **三指/四指向左/右**轻扫，在不同的全屏应用或桌面空间之间切换。
- **📢 通知中心：** 用**两根手指**从触控板的**右边缘**向 左 轻扫。
