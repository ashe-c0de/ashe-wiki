### 🐧 Linux `less` 命令速查笔记

`less` 是 Linux 系统中用于分页查看文件内容的强大工具，特别适合查看大型日志文件。它允许用户自由地向前或向后浏览文件，而无需加载整个文件。

---

#### 1. 常用启动命令

| 命令 | 说明 |
| :--- | :--- |
| `less xxxx.log` | 基本用法：查看文件内容 |
| `less -N xxx.log` | **带行号**查看文件内容 |

---

#### 2. 光标移动与翻页

在 `less` 交互模式下，使用以下按键进行导航：

**行级移动**
- `j` 或 `回车键`：向下移动一行
- `k`：向上移动一行

**屏幕级移动**
- `f` 或 `空格键`：向下滚动一屏幕（下一页）
- `b`：向上滚动一屏幕（上一页）

**文件级定位**
- `g`：定位到文档**头部**
- `G`：定位到文档**最尾部**

---

#### 3. 实时追踪模式 (类似 `tail -f`)

当需要实时监控日志文件的更新时，可以使用此模式。

1.  进入 `less` 模式后，键入 **`F`**（大写）。
2.  此时界面会进入实时滚动状态，效果类似于 `tail -f xxx.log`。
3.  **退出实时滚动**：按下 `Ctrl + c` 即可停止滚动，恢复到普通浏览模式，以便进行查找或翻页。

---

#### 4. 搜索与查找

`less` 支持正则表达式搜索，默认区分大小写。

**向下查找**
- 输入 `/keyword`：向下搜索 "keyword"
- `n`：定位到**下一处**匹配文本
- `N`：定位到**上一处**匹配文本

**向上查找**
- 输入 `?keyword`：向上搜索 "keyword"
- `n`：定位到**上一处**匹配文本
- `N`：定位到**下一处**匹配文本

> **提示**：搜索时输入的命令（如 `/` 或 `?`）会显示在屏幕底部，输入完关键词后按回车执行。

---

#### 5. 退出

- `q`：退出 `less` 查看器，返回命令行终端。
