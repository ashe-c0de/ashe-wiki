# 📝 Vim 常用命令速查笔记

`vim` 是 Linux/Unix 系统中最常用的文本编辑器之一，特别适合查看日志、修改配置文件、编写代码以及远程服务器运维。

---

## 1. 常用启动命令

| 命令 | 说明 |
| :--- | :--- |
| `vim file.txt` | 打开文件 |
| `vim + file.txt` | 打开文件并定位到最后一行 |
| `vim +100 file.txt` | 打开文件并定位到第 100 行 |
| `vim -R file.txt` | 只读模式打开文件 |
| `vimdiff file1 file2` | 对比两个文件 |

---

## 2. Vim 模式说明

Vim 主要有三种常用模式：

| 模式 | 说明 |
| :--- | :--- |
| Normal Mode | 默认模式，用于移动、删除、复制等操作 |
| Insert Mode | 编辑文本 |
| Command Mode | 执行保存、退出、查找替换等命令 |

模式切换：

| 操作 | 按键 |
| :--- | :--- |
| 进入编辑模式 | `i` |
| 在当前行末编辑 | `A` |
| 在下一行编辑 | `o` |
| 返回普通模式 | `Esc` |
| 进入命令模式 | `:` |

## 4. 搜索与查找

### 向下搜索

```vim

```

执行后：

| 按键 | 说明 |
| :--- | :--- |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |

---

### 向上搜索

```vim
?keyword
```

执行后：

| 按键 | 说明 |
| :--- | :--- |
| `n` | 上一个匹配 |
| `N` | 下一个匹配 |

---

### 搜索高亮

## 6. 日志查看常用技巧

### 显示行号

```vim
:set number
```

简写：

```vim
:set nu
```

关闭：

```vim
:set nonumber
```

---

### 查看超长 JSON 日志

关闭自动换行：

```vim
:set nowrap
```

恢复换行：

```vim
:set wrap
```

此时：

| 按键 | 说明 |
| :--- | :--- |
| `zl` | 向右滚动一个字符 |
| `zh` | 向左滚动一个字符 |
| `zL` | 向右滚动半屏 |
| `zH` | 向左滚动半屏 |

## 7. 保存与退出

### 保存

```vim
:w
```

### 退出

```vim
:q
```

### 保存并退出

```vim
:wq
```

或者：

```vim
ZZ
```

### 强制退出不保存

```vim
:q!
```

### 强制保存

```vim
:w!
```
